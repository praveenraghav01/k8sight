Managed Kubernetes

Add cloud clusters without wrestling the CLI

Bring your Amazon EKS, Azure AKS and Google GKE clusters into k8sight and it writes them straight into your kubeconfig, with no cloud CLI to install. Sign in the way each cloud expects: AWS credentials, an Azure system browser flow (works with device Conditional Access), or your existing gcloud login. Any other kubeconfig context works too.

List clusters across regions, generate a short-lived access token and merge the kubeconfig entry, using your existing AWS credentials.
